## Tarjetas de Conoce Tus Derechos

Tarjetas del tamaño de una billetera que explican los derechos constitucionales durante encuentros con autoridades.

**Disponible en:**
- English
- Español (Spanish)
- Soomaali (Somali)
- العربية (Arabic)

**Qué incluye:**
- Declaración de derechos constitucionales
- Qué hacer si agentes vienen a tu casa
- Espacios para contactos de emergencia
- Números de líneas directas

→ **[Imprimir Tarjetas de Derechos](/rights/print-cards/)**

:::tip[DISTRIBUCIÓN]
Imprime estas tarjetas y distribúyelas ampliamente en tu comunidad. Están diseñadas para caber en una billetera y proporcionar información crítica durante encuentros.
:::

## Listas de Verificación

### Lista de Verificación del Equipo Fundador

Usa esto al iniciar una nueva célula con 3-5 personas de confianza.

```
LISTA DE VERIFICACIÓN DE INICIO DEL EQUIPO FUNDADOR

Antes del Lanzamiento:
[ ] 3-5 fundadores identificados y comprometidos
[ ] Todos los fundadores confían profundamente entre sí
[ ] Principios Fundamentales revisados y acordados
[ ] Capacitación de seguridad completada juntos
[ ] Infraestructura de Signal configurada
[ ] Roles de administradores asignados
[ ] Proceso de toma de decisiones acordado
[ ] Horario de reuniones establecido

Primer Mes:
[ ] Segmentos iniciales definidos
[ ] Proceso de incorporación documentado
[ ] Primeros miembros identificados para aval
[ ] Primeras actividades planificadas
[ ] Protocolos de emergencia establecidos
```

---

### Lista de Verificación de Incorporación de Nuevos Miembros

Usa esto para cada nuevo miembro que se una a tu célula.

```
LISTA DE VERIFICACIÓN DE INCORPORACIÓN

Aval:
[ ] El avalista confirma que confía en el prospecto
[ ] Administrador de Incorporación notificado
[ ] Conversación inicial programada

Conversación Inicial:
[ ] Administrador, avalista y prospecto se reúnen
[ ] Célula explicada, preguntas respondidas
[ ] Compromiso y expectativas claras
[ ] Decisión tomada para proceder (o no)

Capacitación de Seguridad:
[ ] Signal instalado y configurado
[ ] Bloqueo de pantalla habilitado
[ ] Bloqueo de registro habilitado
[ ] Mensajes que desaparecen explicados
[ ] Seguridad del dispositivo revisada
[ ] Compartimentación explicada
[ ] Qué NO compartir revisado
[ ] Protocolo de compromiso revisado

Inicio de Período de Prueba:
[ ] Agregado a un grupo de segmento
[ ] Avalista y líder de segmento notificados
[ ] Primeras actividades asignadas
[ ] Horario de verificación establecido

Período de Prueba Completo:
[ ] Evaluación del líder de segmento
[ ] Retroalimentación del avalista
[ ] Estado de confianza confirmado
[ ] Acceso completo al segmento otorgado
```

---

### Lista de Verificación de Auditoría de Seguridad

Realiza esta auditoría mensualmente con todos los miembros.

```
AUDITORÍA DE SEGURIDAD MENSUAL

Para Todos los Miembros:
[ ] Signal aún configurado correctamente
[ ] Bloqueo de teléfono habilitado
[ ] Bloqueo de registro habilitado
[ ] Mensajes que desaparecen activos
[ ] Sin información sensible en capturas de pantalla
[ ] Sin detalles operacionales en otras aplicaciones

Para Líderes de Segmento:
[ ] Todos los miembros siguiendo la compartimentación
[ ] Sin intercambio de información entre segmentos
[ ] Canales de comunicación seguros
[ ] Sin nuevas preocupaciones de seguridad

Para Administradores:
[ ] Proceso de aval siendo seguido
[ ] Sin preocupaciones de confianza con ningún miembro
[ ] Protocolos de emergencia aún vigentes
[ ] Comunicación de respaldo probada
```

## Pautas de Impresión

### Para Tarjetas de Derechos
- Imprime en cartulina para durabilidad
- Corta a lo largo de las líneas punteadas
- Dobla al tamaño de billetera
- Lamina si es posible

### Para Listas de Verificación
- Imprime en papel regular
- Usa una por miembro/actividad
- Destruye después de completar
- Nunca almacenes digitalmente

### Para Tarjetas de Roles
- Imprime en cartulina
- Entrega a los miembros durante la incorporación
- Reemplaza si se pierde (no guardes copias)

---

:::caution[RECORDATORIO DE SEGURIDAD]
**Nunca almacenes formularios completados digitalmente.** Mantén copias físicas en un lugar seguro. Destruye formularios cuando los miembros dejen la célula.
:::
