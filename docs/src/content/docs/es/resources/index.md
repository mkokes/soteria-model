## Categorías de Recursos

### 🔧 Recursos Técnicos

Herramientas y plataformas esenciales para coordinación segura:

- **[Signal](https://signal.org)** — Mensajería encriptada (herramienta de comunicación principal)
- **[CryptPad](https://cryptpad.fr)** — Documentos colaborativos encriptados
- **[Tor Browser](https://www.torproject.org)** — Navegación web anónima
- **Guías de seguridad de dispositivos** — Protección de teléfonos y computadoras

→ **[Ver todas las herramientas técnicas](/es/resources/technical/)**

### 📄 Materiales Imprimibles

Recursos listos para imprimir para tu comunidad:

- **Tarjetas de derechos** en inglés, español, somalí y árabe
- **Listas de verificación de incorporación** para nuevos miembros
- **Plantillas de auditoría de seguridad** para revisiones mensuales
- **Tarjetas de roles de segmento** que explican responsabilidades
- **Formularios de contacto de emergencia**

→ **[Ver todos los materiales imprimibles](/es/resources/printable/)**

### 📚 Guías de Implementación

Instrucciones paso a paso para iniciar y operar una célula:

- **[Guía del Equipo Fundador](/es/start-a-cell/founding-team/)** — Cómo comenzar con 3-5 personas de confianza
- **[Configuración de Signal](/es/start-a-cell/signal-setup/)** — Configuración de mensajería segura
- **[Proceso de Incorporación](/es/start-a-cell/onboarding/)** — Verificación y capacitación de nuevos miembros
- **[Prácticas de Seguridad](/es/security/)** — Fundamentos de seguridad operacional
