**الموارد الجاهزة للطباعة لمجتمعك وعمليات الخلية.**

جميع المواد في هذه الصفحة مصممة للطباعة والمشاركة والاستخدام في الموقع. قم بتخصيصها لسياقك المحلي.

## بطاقات اعرف حقوقك

بطاقات بحجم الجيب تشرح الحقوق الدستورية أثناء اللقاءات مع السلطات.

**متاحة بـ:**
- English
- Español (Spanish)
- Soomaali (Somali)
- العربية (Arabic)

**تتضمن:**
- بيان الحقوق الدستورية
- ما يجب فعله إذا جاء عملاء إلى منزلك
- مساحات جهات الاتصال الطارئة
- أرقام خطوط المساعدة

→ **[اطبع بطاقات الحقوق](/ar/rights/print-cards/)**

:::tip[التوزيع]
اطبع هذه البطاقات ووزعها على نطاق واسع في مجتمعك. إنها مصممة لتناسب الجيوب وتوفر معلومات حاسمة أثناء اللقاءات.
:::

## قوائم التحقق

### قائمة تحقق الفريق المؤسس

استخدم هذا عند بدء خلية جديدة بـ 3-5 أشخاص موثوقين.

```
قائمة تحقق بدء الفريق المؤسس

قبل البدء:
[ ] تم تحديد 3-5 مؤسسين ملتزمين
[ ] جميع المؤسسين يثقون ببعضهم البعض بعمق
[ ] تمت مراجعة المبادئ الأساسية والاتفاق عليها
[ ] تم إكمال التدريب الأمني معًا
[ ] تم إعداد حسابات Signal
[ ] تم تعيين أدوار المسؤولين
[ ] تم الاتفاق على عملية صنع القرار
[ ] تم إنشاء جدول الاجتماعات

الشهر الأول:
[ ] تم تحديد الأقسام الأولية
[ ] تم توثيق عملية الإعداد
[ ] تم تحديد الأعضاء الأوائل بأمان
[ ] تم التخطيط للعمليات الأولى
[ ] تم إنشاء بروتوكول الطوارئ
```

---

### قائمة تحقق إعداد الأعضاء الجدد

استخدم هذا لكل عضو جديد ينضم إلى خليتك.

```
قائمة تحقق الإعداد

الفحص:
[ ] يؤكد الضامن أنه يثق بالمرشح
[ ] تم إخطار مسؤول الإعداد
[ ] تم جدولة المحادثة الأولية

المحادثة الأولية:
[ ] يجتمع المسؤول والضامن والمرشح
[ ] تم شرح الخلية، تم الإجابة على الأسئلة
[ ] الالتزام والتوقعات واضحة
[ ] تم اتخاذ القرار بالمتابعة (أو لا)

التدريب الأمني:
[ ] تم تثبيت وإعداد Signal
[ ] تم تمكين قفل الشاشة
[ ] تم تمكين قفل التسجيل
[ ] تم شرح الرسائل المختفية
[ ] تمت مراجعة أمن الأجهزة
[ ] تم شرح التقسيم
[ ] تمت مراجعة ما لا يجب مشاركته
[ ] تمت مراجعة بروتوكول إدارة المخاطر

بدء الفترة التجريبية:
[ ] تمت الإضافة إلى مجموعة القسم
[ ] تم إخطار الضامن وقائد القسم
[ ] تم تعيين المهام الأولى
[ ] تم تحديد جدول التحقق

اكتمال الفترة التجريبية:
[ ] تقييم قائد القسم
[ ] ملاحظات الضامن
[ ] تم تأكيد حالة الثقة
[ ] تم منح الوصول الكامل للقسم
```

---

### قائمة تحقق تدقيق الأمان

قم بإجراء هذا التدقيق شهريًا لجميع الأعضاء.

```
تدقيق الأمان الشهري

جميع الأعضاء:
[ ] Signal لا يزال مُعدًا بشكل صحيح
[ ] قفل الهاتف ممكّن
[ ] قفل التسجيل ممكّن
[ ] الرسائل المختفية نشطة
[ ] لا توجد معلومات حساسة في لقطات الشاشة
[ ] لا توجد تفاصيل تشغيلية في تطبيقات أخرى

قادة الأقسام:
[ ] جميع الأعضاء يتبعون التقسيم
[ ] لا توجد مشاركة معلومات بين الأقسام
[ ] قنوات الاتصال آمنة
[ ] لا توجد مخاوف أمنية جديدة

المسؤولون:
[ ] يتم اتباع بروتوكول الفحص
[ ] لا توجد مخاوف ثقة بشأن الأعضاء
[ ] بروتوكول الطوارئ لا يزال حديثًا
[ ] تم اختبار اتصالات النسخ الاحتياطي
```

## بطاقات دور القسم

اطبع هذه البطاقات لمساعدة الأعضاء على فهم مسؤوليات قسمهم.

```

│  المراقبة والإنذار المبكر           │

│  دورك:                              │
│  • مراقبة النشاط المشبوه            │
│  • الإبلاغ عبر قنوات آمنة           │
│  • توفير الإنذار المبكر             │
│                                     │
│  أبداً:                             │
│  • لا تعرف طرق النقل                │
│  • لا تعرف مواقع الموارد            │
│  • لا تعرف عناوين المنازل الآمنة    │
│                                     │
│  ابق في مسارك                       │
└─────────────────────────────────────┘
```

## إرشادات الطباعة

### بطاقات الحقوق
- اطبع على ورق سميك للمتانة
- قص على طول الخطوط المنقطة
- اطوِ إلى حجم الجيب
- قم بالتغليف إن أمكن

### قوائم التحقق
- اطبع على ورق عادي
- استخدم واحدة لكل عضو/عملية
- دمر بعد الانتهاء
- لا تحفظ رقميًا أبدًا

### بطاقات الدور
- اطبع على ورق سميك
- أعطِ للأعضاء أثناء الإعداد
- استبدل إذا فُقدت (لا تحتفظ بنسخ)

---

:::caution[تذكير أمني]
**لا تحفظ النماذج المكتملة رقميًا أبدًا.** احتفظ بنسخ مادية في مكان آمن. دمر النماذج عند مغادرة الأعضاء للخلية.
:::
