## أقسام الموارد

### 🔧 الموارد التقنية

الأدوات والمنصات الأساسية للتنسيق الآمن:

- **[Signal](https://signal.org)** — المراسلة المشفرة (أداة الاتصال الأساسية)
- **[CryptPad](https://cryptpad.fr)** — التوثيق التعاوني المشفر
- **[Tor Browser](https://www.torproject.org)** — تصفح الإنترنت المجهول
- **أدلة أمن الأجهزة** — حماية الهواتف وأجهزة الكمبيوتر

→ **[عرض جميع الأدوات التقنية](/ar/resources/technical/)**

### 📄 المواد القابلة للطباعة

الموارد الجاهزة للطباعة لمجتمعك:

- **بطاقات الحقوق** English، Español، Soomaali، والعربية
- **قوائم تحقق الإعداد** للأعضاء الجدد
- **قوالب تدقيق الأمان** للمراجعة الشهرية
- **بطاقات دور القسم** تشرح المسؤوليات
- **نماذج جهات الاتصال الطارئة**

→ **[عرض جميع المواد القابلة للطباعة](/ar/resources/printable/)**

### 📚 أدلة التنفيذ

تعليمات خطوة بخطوة لبدء وإدارة خلية:

- **[دليل الفريق المؤسس](/ar/start-a-cell/founding-team/)** — كيفية البدء بـ 3-5 أشخاص موثوقين
- **[إعداد Signal](/ar/start-a-cell/signal-setup/)** — إعداد المراسلة الآمنة
- **[عملية الإعداد](/ar/start-a-cell/onboarding/)** — فحص وتدريب الأعضاء الجدد
- **[ممارسات الأمان](/ar/security/)** — أساسيات الأمن التشغيلي

### 🌍 الموارد متعددة اللغات

الوثائق متاحة بلغات متعددة:

- **English** (كامل)
- **Español / Spanish** (89% كامل)
- **Soomaali / Somali** (89% كامل)
- **العربية / Arabic** (89% كامل)

ابحث عن المحتوى المترجم عبر محدد اللغة في قائمة التنقل.

## استخدام هذه الموارد

### الأفراد

إذا كنت تتعلم عن النموذج أو تفكر في بدء خلية:

1. ابدأ بـ **[النموذج](/ar/model/)** لفهم الهيكل
2. راجع **[ممارسات الأمان](/ar/security/)** لفهم الأمن التشغيلي
3. استكشف **[الأدوات التقنية](/ar/resources/technical/)** لرؤية المنصات التي ستستخدمها
4. قم بتنزيل **[بطاقات الحقوق](/ar/rights/print-cards/)** لحملها معك

### الفرق المؤسسة

إذا بدأت خلية بـ 3-5 أشخاص موثوقين:

1. أكمل **[دليل الفريق المؤسس](/ar/start-a-cell/founding-team/)**
2. قم بإعداد **[Signal](/ar/start-a-cell/signal-setup/)** لجميع المؤسسين
3. استخدم **[قوائم التحقق القابلة للطباعة](/ar/resources/printable/)** لتتبع التقدم
4. راجع **[عملية الإعداد](/ar/start-a-cell/onboarding/)** قبل إضافة الأعضاء

### الخلايا النشطة

إذا كنت تدير خلية راسخة:

1. قم بإجراء **[تدقيق الأمان](/ar/resources/printable/#قائمة-تحقق-تدقيق-الأمان)** شهريًا
2. استخدم **[القوالب](/ar/resources/printable/)** للعمليات المنتظمة
3. وزع **[بطاقات الحقوق](/ar/rights/print-cards/)** على أعضاء المجتمع
4. راجع **[ممارسات الأمان](/ar/security/)** بانتظام مع جميع الأعضاء
